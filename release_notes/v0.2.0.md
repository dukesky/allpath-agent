# Allpath Agent v0.2.0

Released: 2026-07-29

Allpath Agent v0.2.0 moves the project from a local chat MVP toward a small,
practical personal agent. It adds workspace and terminal execution, progressive
Skills, MCP tools, scheduled automation, self-serve connector onboarding, and a
clearer terminal experience while keeping the core narrow and approval-driven.

## Highlights

### Workspace agent capabilities

- Read and search UTF-8 files inside the startup workspace with traversal,
  symlink, credential-file, binary, dependency-directory, and size boundaries.
- Write and patch files through explicit approval, atomic replacement, and
  SHA-256 compare-and-swap protection against stale edits.
- Run bounded argv-only terminal commands from an executable allowlist with a
  secret-stripped environment, workspace cwd enforcement, timeouts, process
  group termination, and output limits.
- Record tool execution and approval outcomes in SQLite for evidence-driven
  curriculum progress.

### Skills and MCP

- Discover built-in, user, and project Skills with predictable override order.
- List Skill metadata separately and load full Skill instructions only when
  invoked, preserving a stable system prompt and prompt-cache-friendly core.
- Include initial repository analysis, connector setup, and automation Skills.
- Discover and invoke namespaced stdio MCP tools through the official Python
  SDK with schema normalization, explicit environment allowlisting, workspace
  cwd enforcement, timeout limits, and side-effect approval.

### Automation and proactive foundations

- Create timezone-aware one-time and five-field cron jobs backed by SQLite.
- Atomically claim due jobs, execute them through the same AgentApplication,
  retain bounded results, and support safe connector delivery.
- Add a typed Hook Bus for Agent lifecycle, connector message, and automation
  completion events without logging prompts, message bodies, tool arguments,
  credentials, or provider responses.

### Progressive onboarding

- Track `tried`, `succeeded`, and `habitual` capability states from verified
  execution evidence rather than only showing tips.
- Expand the curriculum to workspace files, terminal tasks, Skills, MCP,
  messaging connectors, and scheduled automations.
- Provide resumable conversational Telegram, Slack, and WhatsApp tutorials with
  numbered steps, progress, back/status/cancel navigation, hidden secret input,
  verification, diagnostics, and corrective next actions.

### Terminal experience

- Present user input in a visible `YOU` composer and model output in distinct
  `ALLPATH · <ROLE>` panels.
- Show privacy-safe task, model retry, and tool progress as compact activity
  lines instead of leaving the user at a silent prompt.
- Display side-effect requests in a bordered `APPROVAL` panel with bounded
  argument previews.
- Keep onboarding suggestions separate from answers in `NEXT` cards.

## Safety boundaries

- The terminal never invokes a shell and blocks destructive Git operations.
- Workspace mutation remains approval-gated and rooted to the startup folder.
- MCP receives only explicitly configured environment variables.
- Browser and computer-use automation remain disabled until the documented
  structured-element, isolated-profile, approval, visibility, and interruption
  gates are implemented.

## Validation

- 200 standard-library unit and integration tests pass locally.
- Source compilation and `git diff --check` pass.
- Installed CLI smoke tests cover Skills and MCP discovery.
- Real PTY tests cover the user composer, activity stream, tool approval, and
