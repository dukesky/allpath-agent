# Create Automation

1. Clarify the task, schedule, timezone, and destination.
2. Prefer a one-time schedule when recurrence is not explicit.
3. For cron, explain the resolved schedule in plain language before creation.
4. Keep the automation prompt self-contained because it runs in a dedicated session.
5. Verify the stored job and next run time.
6. Never claim delivery succeeded until an automation run and connector delivery are recorded as successful.
